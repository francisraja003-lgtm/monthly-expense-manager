EXECUTIVE SUMMARY
================================================================================

The Monthly Expense Manager is a comprehensive desktop application built with 
Python that helps users track their daily expenses, manage monthly budgets, 
visualize spending patterns through interactive charts, and generate professional 
PDF reports. The application addresses a significant real-world problem: most 
people struggle to track where their money goes, making it difficult to stay 
within budgets and plan their finances effectively. This complete solution 
provides users with a secure, offline-first platform that gives them full 
visibility into their financial spending with real-time alerts when they exceed 
their set budget limits. The entire project is built from scratch with 
production-ready code quality, comprehensive test coverage, and a professional 
user interface that supports both light and dark themes.

================================================================================

PROBLEM STATEMENT
================================================================================

In today's world, personal financial management is more important than ever, yet 
most people lack effective tools to track their spending. The problem is 
multifaceted: people don't have a centralized place to record all their expenses, 
they cannot easily see where their money is being spent, they struggle to stick 
to monthly budgets because they lack real-time visibility, and they have no 
simple way to generate reports for financial analysis or record-keeping. 
Traditional solutions like spreadsheets require manual data entry and are prone 
to errors, while online applications require internet connectivity and raise 
privacy concerns by storing sensitive financial data in the cloud. Paper-based 
tracking is tedious and unsearchable, and other desktop applications often lack 
either features or professional quality. This gap in the market created the need 
for a solution that is complete, secure, offline, and easy to use.

PROJECT OVERVIEW
================================================================================

The Monthly Expense Manager is a full-featured desktop application that runs on 
Windows, Mac, and Linux without requiring internet connectivity. The application 
provides users with a complete financial management system built entirely with 
Python using Tkinter for the graphical user interface, SQLite for local data 
storage, and Matplotlib for data visualization. The project consists of over 
6,000 lines of well-organized, professionally written code distributed across 15 
Python files, with 99 comprehensive unit tests that all pass successfully. The 
application implements 20+ core features including secure user authentication, 
expense tracking and management, budget monitoring with real-time alerts, 
interactive dashboards with charts, professional PDF report generation, and a 
beautiful user interface with both light and dark theme support. The project is 
completely production-ready, meaning it can be used immediately for actual 
expense tracking or can serve as a portfolio piece to demonstrate advanced 
software development capabilities.

CORE FEATURES EXPLAINED
================================================================================

The Monthly Expense Manager offers a comprehensive set of features designed to 
solve every aspect of personal financial management. The user authentication 
system provides secure login and signup functionality with passwords hashed 
using SHA-256 encryption, ensuring that user credentials are never stored in 
plaintext and that each user's data remains completely isolated and private. 
The expense tracking feature allows users to easily add new expenses by entering 
the amount, selecting a category from a dropdown list of ten predefined 
categories, picking a date using an intuitive calendar widget, and optionally 
adding a description. Users can view all their expenses in a sortable table, 
edit existing expenses through an inline dialog, delete expenses with 
confirmation, and search or filter expenses by category, date range, or amount 
range. The budget management system enables users to set monthly spending limits 
for each category and provides a "Quick Set" feature that applies the same budget 
limit to all categories at once with a single click. When spending exceeds budget 
limits, the application displays prominent red alerts and warning banners to 
notify the user immediately. The dashboard provides a comprehensive overview with 
summary cards showing total spent, total budget, and remaining budget, along with 
interactive pie and bar charts showing spending by category and how actual 
spending compares to budgeted amounts. The application supports exporting data to 
CSV format for use in spreadsheets and can generate professional multi-page PDF 
reports that include summary statistics, embedded charts, category breakdowns, 
and detailed expense tables with proper formatting and page numbers. Finally, the 
theme system allows users to toggle between light mode for professional use and 
dark mode for eye comfort, with all UI elements updating instantly when the theme 
changes.

TECHNICAL ARCHITECTURE
================================================================================

The application is built using a clean, well-organized three-layer architecture 
that separates concerns between the user interface, business logic, and data 
persistence layers. The presentation layer uses Tkinter, Python's built-in GUI 
framework, combined with ttk (themed widget toolkit) to create a modern, 
professional interface across all major operating systems. The main application 
window is divided into five tabs: a dashboard showing analytics and alerts, a 
form for adding new expenses, a table for viewing and managing existing expenses, 
a settings area for configuring budgets, and an authentication screen for login 
and signup. Behind the scenes, the business logic layer contains the analytics 
module that performs all calculations for budgets and generates data for charts, 
the utils module that handles validation and formatting of all inputs and outputs, 
and the report generator that creates professional PDF documents. The data 
persistence layer uses SQLite, a lightweight but powerful relational database 
that stores all application data locally on the user's computer. The database 
consists of three main tables: the users table stores login credentials and 
authentication information, the expenses table stores all recorded transactions, 
and the budgets table stores the monthly spending limits for each category. All 
database operations are performed through a dedicated operations module that 
implements all Create, Read, Update, and Delete (CRUD) operations with full error 
handling and validation. This layered architecture ensures that the code is 
modular, maintainable, and easy to test, with clear responsibilities for each 
component.

================================================================================

DATABASE AND DATA MANAGEMENT
================================================================================

The application uses SQLite as its database management system, which is ideal for 
desktop applications because it requires no separate server, stores data in a 
single local file, and provides full relational database capabilities. The 
database schema consists of three carefully designed tables that work together to 
store all application data securely and efficiently. The users table stores 
usernames and password hashes, with each user identified by a unique ID. The 
expenses table contains every expense recorded by users, including the amount in 
Indian Rupees, the category, the date, and an optional description, with a 
foreign key linking each expense to the user who recorded it. The budgets table 
stores the monthly spending limit for each category for each user, again using a 
foreign key to associate each budget with a specific user. This design ensures 
complete data isolation between users so that each person sees only their own 
data, provides referential integrity through foreign key constraints, and 
maintains security through the separation of sensitive authentication data from 
expense data. All amounts are stored as currency values, all dates are stored in 
a standard ISO format (YYYY-MM-DD) for consistency, and all user-entered data is 
validated before being saved to the database to prevent corruption or security 
vulnerabilities.

================================================================================

SECURITY AND PRIVACY CONSIDERATIONS
================================================================================

Security and privacy are fundamental to the design of the Monthly Expense Manager. 
User passwords are never stored in plaintext; instead, they are hashed using the 
SHA-256 cryptographic hash function before being saved to the database, which 
means that even if someone gains access to the database file, they cannot recover 
the original passwords. User data is completely isolated at the database level, 
with all queries automatically scoped to the current user through the user_id 
field, ensuring that a user logged into one account cannot see or access data 
from any other account on the same computer. All data is stored locally on the 
user's computer in the SQLite database file; it is never transmitted over the 
internet and is never stored on a cloud server, giving users complete ownership 
and control of their financial information. Every piece of user input is 
validated before being used or saved, with strict checks on data types (amounts 
must be numbers), data ranges (amounts cannot exceed 10 crore rupees), and data 
formats (dates must be valid). The application uses parameterized database queries 
throughout to prevent SQL injection attacks, and all error messages are carefully 
designed to provide helpful feedback to users without revealing sensitive 
information that could be exploited by attackers.

MAJOR BUG FIXES AND IMPROVEMENTS
================================================================================

During development and refinement of the Monthly Expense Manager, several 
important bugs were identified and fixed to ensure the application works 
correctly. The most significant bug involved the edit expense functionality, where 
users could open a dialog to modify an existing expense but clicking the save 
button would not actually persist the changes to the database. This was caused by 
missing validation of the return value from the database update function; the 
code assumed the update was successful without checking, so failures went 
unnoticed. The fix involved adding proper success checking and displaying an error 
message to the user if the update failed. Another important fix involved date 
format conversion, where the date picker widget returns dates in dd/mm/yyyy format 
but the database stores dates in YYYY-MM-DD format, causing inconsistencies and 
validation errors. This was resolved by adding a conversion function that properly 
transforms the date from the display format to the storage format. An additional 
improvement involved removing an unnecessary month and year selector dropdown from 
the dashboard, which simplified the interface and focused the user's attention on 
the current month's data. These fixes demonstrate the importance of thorough 
testing and careful attention to detail in ensuring that applications work as 
intended.

INSTALLATION AND DEPLOYMENT
================================================================================

The Monthly Expense Manager is remarkably easy to install and deploy on any 
computer with Python 3.10 or higher installed. The installation process begins by 
cloning the project from GitHub, which creates a local copy of all source code. 
Next, a Python virtual environment is created to isolate the project's 
dependencies from other Python projects on the system, preventing version 
conflicts. The required packages are then installed using pip, Python's package 
manager, by running a simple command that reads from a requirements.txt file 
listing all external dependencies. Finally, the application is launched by running 
the main.py file, which starts the application and automatically creates the 
SQLite database file if it doesn't already exist. The entire installation process 
takes only a few minutes and requires no configuration; the application is ready 
to use immediately after installation. The only external dependency is that 
Python 3.10+ and pip must be installed on the system, but these are standard 
tools available on virtually all computers. The application stores all data 
locally in the expense_manager.db file, making it portable; users can copy the 
application folder and database file to another computer and continue using their 
data immediately. This simplicity of deployment makes the application accessible 
to users without technical expertise.

PROJECT STRUCTURE AND ORGANIZATION
================================================================================

The Monthly Expense Manager follows a well-organized project structure that 
separates concerns and makes the codebase easy to navigate and understand. The 
main entry point is main.py, which initializes the application and manages the 
overall flow including authentication and window management. The database layer 
consists of database.py which defines the SQLite schema and handles database 
initialization, models.py which defines Python dataclasses representing the core 
data types (User, Expense, Budget), and operations.py which implements all 
database operations with complete error handling. The business logic layer 
includes analytics.py which contains functions for calculating budget statistics 
and generating chart data, utils.py which contains validation and formatting 
functions used throughout the application, and report_generator.py which handles 
the creation of PDF reports. The GUI layer is organized into a gui/ subdirectory 
containing auth.py for the login and signup interface, dashboard_tab.py for the 
main dashboard view, add_expense_tab.py for the expense entry form, 
view_expenses_tab.py for viewing and managing expenses, settings_tab.py for 
budget configuration, and theme.py which manages the light and dark themes. The 
tests/ subdirectory contains all unit tests organized into test_operations.py for 
database operations, test_analytics.py for calculations, and test_utils.py for 
validation and formatting. Additional utility scripts include _check.py for 
pre-launch validation, _gen_sample_pdf.py for generating sample PDFs, and 
_verify_fixes.py for verifying that specific bugs have been fixed. This 
organization makes it clear where to look for any specific functionality and makes 
it easy for new developers to understand and contribute to the codebase.
