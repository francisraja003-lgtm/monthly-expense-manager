## FREQUENTLY ASKED QUESTIONS

**Q: How secure is the password storage?**
A: Passwords are hashed with SHA-256 before storing in database. Never plaintext.

**Q: Can multiple users use this on the same computer?**
A: Yes, each user has separate login and isolated data.

**Q: Where is the data stored?**
A: SQLite database file (expense_manager.db) stored locally on computer.

**Q: Can I use this on Mac/Linux?**
A: Yes, it's cross-platform. Works on Windows, Mac, and Linux.

**Q: Is internet required?**
A: No, it's fully offline. No cloud dependency.

**Q: Can I export my data?**
A: Yes, CSV and PDF exports are supported.

**Q: How much does it cost?**
A: It's free. Open source on GitHub.

**Q: Can I add more features?**
A: Yes, the code is well-organized for extensions.
```
