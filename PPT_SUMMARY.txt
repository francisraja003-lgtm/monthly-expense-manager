SLIDE 5: DATABASE DESIGN
================================================================================

TITLE: How Data is Stored

USERS TABLE:
- id (unique identifier)
- username (unique login name)
- password_hash (encrypted password, not plaintext)

EXPENSES TABLE:
- id (unique identifier)
- user_id (which user owns this)
- amount (how much in rupees)
- category (type of expense)
- date (when the expense happened)
- description (details)

BUDGETS TABLE:
- id (unique identifier)
- user_id (which user owns this)
- category (which category)
- limit (monthly budget amount)

KEY DESIGN DECISIONS:
✓ Each user has their own isolated data
✓ Passwords are hashed for security
✓ All amounts in Indian Rupees (₹)
✓ Dates stored as YYYY-MM-DD format
✓ Foreign keys ensure data integrity

SLIDE 6: USER JOURNEY / HOW IT WORKS
================================================================================

TITLE: What Happens When User Uses the App

STEP 1: FIRST TIME LAUNCH
- User runs: python main.py
- Database is created automatically
- Login screen appears

STEP 2: SIGN UP
- User clicks "Create Account"
- Enters username (min 3 characters)
- Enters password (min 6 characters)
- Password is hashed with SHA-256
- Account is created in database

STEP 3: LOGGED IN - SEE DASHBOARD
- Dashboard shows:
  * Summary cards (Spent, Budget, Remaining)
  * Spending chart (pie or bar)
  * Budget alerts (if over budget)

STEP 4: ADD EXPENSES
- User goes to "Add Expense" tab
- Fills form: Amount, Category, Date, Description
- Clicks "Save Expense"
- Appears immediately in expense table

STEP 5: SET BUDGETS
- User goes to "Settings" tab
- Enters category and monthly limit
- Clicks "Save Budget"
- Can use "Quick Set" to apply to all categories

STEP 6: VIEW & MANAGE
- User goes to "View/Manage" tab
- Sees table of all expenses
- Can apply filters (category, date, amount)
- Can sort by any column
- Can edit by double-clicking
- Can delete with confirmation

STEP 7: GENERATE REPORT
- User clicks "Download PDF"
- Selects where to save file
- PDF is generated with:
  * Summary information
  * Charts
  * Expense tables
  * Page numbers

STEP 8: LOGOUT
- User clicks "Logout"
- Returns to login screen
- All data is saved

SLIDE 11: IMPROVEMENTS MADE
================================================================================

TITLE: Bug Fixes & Enhancements

BUG FIX 1: EDIT EXPENSE SAVE NOT WORKING
PROBLEM: When user clicked "Save Changes", the expense wasn't saved to database
CAUSE: Code wasn't checking if update was successful
FIX: Added success validation and error handling
RESULT: Save button now works perfectly

BUG FIX 2: DATE FORMAT CONVERSION
PROBLEM: Date picker returns dd/mm/yyyy but database needs YYYY-MM-DD
CAUSE: Missing format conversion in _get_date() method
FIX: Added conversion function to transform date format
RESULT: Dates save correctly to database

BUG FIX 3: REMOVED MONTH SELECTOR FROM DASHBOARD
PROBLEM: Month/year dropdown was cluttering dashboard
SOLUTION: Removed selector, dashboard now shows current month only
RESULT: Cleaner, simpler interface

ENHANCEMENT: COMPREHENSIVE ERROR MESSAGES
- Users know exactly what went wrong
- Helpful suggestions for fixing errors
- No cryptic error codes

ENHANCEMENT: INPUT RESTRICTIONS
- Prevent invalid data at keyboard level
- Can't type letters in amount field
- Date picker prevents invalid dates

SLIDE 12: INSTALLATION & SETUP
================================================================================

TITLE: How to Get Started

REQUIREMENTS:
- Python 3.10 or higher
- pip (Python package manager)
- 100 MB disk space

INSTALLATION STEPS:

Step 1: Clone Repository
$ git clone https://github.com/francisraja003-lgtm/monthly-expense-manager.git
$ cd expense_manager_gui

Step 2: Create Virtual Environment (optional but recommended)
$ python -m venv venv
$ source venv/bin/activate  (On Mac/Linux)
$ venv\Scripts\activate     (On Windows)

Step 3: Install Required Packages
$ pip install -r requirements.txt

Step 4: Run Application
$ python main.py

FIRST RUN:
- Database (expense_manager.db) is created automatically
- Login screen appears
- Click "Create Account" to sign up
- Start tracking expenses!
